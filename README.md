# C00 — ex05 · ft_print_comb

Выводит все сочетания трёх **разных** цифр в возрастающем порядке,
от `012` до `789`, через запятую с пробелом. Всего 120 сочетаний,
после последнего разделителя нет.

```
012, 013, 014, ..., 679, 689, 789
```

## Условия задания

| | |
|---|---|
| Файл | `ft_print_comb.c` |
| Прототип | `void ft_print_comb(void);` |
| Разрешено | `write` |

## Проверка

```sh
cc -Wall -Wextra -Werror ft_print_comb.c main.c && ./a.out
```

Собирается без предупреждений, шапка 42 на месте, норма соблюдена:
строки до 80 символов, отступы табами, тело функции 24 строки.
